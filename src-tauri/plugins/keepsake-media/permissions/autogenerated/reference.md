## Default Permission

Allows the transcode command (Android audio conversion to M4A or WAV) and open_file (open a download in another app), and ytdlp_status / ytdlp_info / ytdlp_download / ytdlp_cancel / ytdlp_mux (yt-dlp with bundled QuickJS and ffmpeg for TikTok, Instagram and YouTube on Android), gallery_publish (save a finished download to the Android Gallery via MediaStore), folder_pick / folder_status / folder_save (save into a user-chosen folder through the Storage Access Framework), editor_probe / editor_export_video / editor_cancel (video crop, trim and mute export on Media3 Transformer), and register_listener / remove_listener (the keepsake-editor-progress plugin event).

#### This default permission set includes the following:

- `allow-transcode`
- `allow-open-file`
- `allow-ytdlp-status`
- `allow-ytdlp-info`
- `allow-ytdlp-download`
- `allow-ytdlp-cancel`
- `allow-ytdlp-mux`
- `allow-gallery-publish`
- `allow-folder-pick`
- `allow-folder-status`
- `allow-folder-save`
- `allow-editor-probe`
- `allow-editor-export-video`
- `allow-editor-cancel`
- `allow-register-listener`
- `allow-remove-listener`
